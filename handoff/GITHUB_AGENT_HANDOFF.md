# GITHUB AGENT HANDOFF

**Будь-який агент, що працює з цим репозиторієм, може підхопити роботу будь-коли
і передати її будь-коли.** Цей файл — єдина точка входу. Знати про нього
зобов'язаний кожен: Claude Code, Codex, і будь-хто наступний.

Тут не історія і не звіт. Тут відповідь на одне питання: **де саме зупинилась
робота і що робити далі.** Працює в обидві сторони — Codex підхоплює за
Claude Code і навпаки, у будь-який момент, без уточнень у чаті.

## Стартова команда

```bash
cd ~/wardrobe-claude-code-20260727-557761 && git pull --rebase --autostash origin beta && node ops/runtime.mjs --verify && sed -n '1,80p' handoff/LIVE_STATUS.md
```

Три речі одразу: свіжа гілка, перевірений стан інфраструктури, і останні записи
про те, хто що робив хвилину тому.

Якщо клону ще немає — спершу підняти себе як агента:

```bash
bash <(gh api -H 'Accept: application/vnd.github.raw' 'repos/edwin0912-00/zeely-ai-engineering-test/contents/tools/bootstrap-beta-agent.sh?ref=beta') --watch
```

## Що читати, у якому порядку

1. `handoff/LIVE_STATUS.md` — живий статус: останній `INTENT`, `PROGRESS`,
   `BLOCKED` або `DONE` кожного агента.
2. `ops/RUNTIME.json` — операційна правда: де хост, який реліз, який провайдер
   живий і чому. Оновлюється командою, не руками.
3. `UPDATE.md` — дошка задач і хто які шляхи зайняв.
4. `docs/AGENT_RESUME_HANDOFF_UA.md` — де лежать матеріали, що доведено, що не
   закінчено.
5. Канони: `spec/ZEELY_CANON_UA.md` (продукт), `docs/UI_JOURNEY_CANON_UA.md`
   (UI-шлях), `docs/VIDEO_LIVE_CANON_UA.md` (рух і Live).

## Правило, яке робить це працюючим

**Дія, довша за кілька хвилин, спершу пишеться в GitHub, потім робиться.** Не
після — до. Разом із задумом, а не тільки з назвою.

```bash
node ops/intent.mjs start "переношу ходу на вулицю: нова environment-дошка + реshoot" --files "docs/style-units/**"
node ops/intent.mjs step  "дошка згенерована, кадр перезнятий, гардероб втримався"
node ops/intent.mjs done  "закомічено 9eb0d1d, палітра ще не заміряна"
```

Кожен виклик додає запис у `handoff/LIVE_STATUS.md`, комітить і пушить сам.
Якщо агента обрізало посеред дії — останній `INTENT` уже в GitHub, і той, хто
приходить, бачить не «щось робилось», а що саме, з якими файлами і від якого
HEAD.

`BLOCKED` — не соромно, це найцінніший запис: він економить наступному ту саму
годину.

## Дві доріжки

- **HANDOFF-CLAUDE-CODE** — усі чати Claude Code. Ідентифікатори виду
  `claude-code-<дата>-<суфікс>`.
- **HANDOFF-CODEX** — усі агенти Codex: `codex-main`, `codex-live-*`,
  `codex-video-fidelity-*`.

Обидві пишуть в один `LIVE_STATUS.md`, бо сенс саме в тому, щоб бачити чуже.
Розділення потрібне лише для того, щоб знати, кого просити продовжити.

## Перевірка перед активацією релізу

`node ops/runtime.mjs --verify` друкує двосторонню звірку живого каталогу з тим
комітом, який збираються активувати. Рядок `WOULD LOSE` мусить бути порожнім —
інакше активація видалить стиль, який зараз в ефірі.
