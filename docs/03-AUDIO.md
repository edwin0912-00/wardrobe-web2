# Звук

`audio.js`. Одна кімната (convolver reverb), один шар ехо, керовані швидкістю скролу.

## Реверб — постійний, не залежить від швидкості

`reverbWet.gain.value = 0.15` (15% — точне число власника). Це БУЛО прив'язано до
швидкості (росло до 0.55 залишку headroom при русі), але це змушувало два ефекти
відповідати на один жест і замулювало ехо, яке мало нести рух. Тепер кімната стала —
вона не «стає більш бетонною», коли ви швидше скролите.

## Ехо — по синусоїді до 80%

```
shaped = 0.5 - 0.5 * Math.cos(Math.PI * clamp01(speed))   // те саме рівняння, що easeSine
echoWet.gain    -> maxEcho * shaped      // maxEcho = 0.80
feedback.gain   -> maxFeedback * shaped  // maxFeedback = 0.66
```
Раніше це був степеневий вигин (`Math.pow(s, curve)`), який або лишав ordinary-скрол сухим,
або бив хардово тільки на фліку. Синусоїда симетрична: м'яко зі стану спокою, найкрутіше
посередині, плавно в стелю — той самий профіль руху, що й камера, тому кімната й картинка
дихають в один такт.

## Передача треків без накладання

Три треки, `t2`/`t3` — виявились ДВОМА рендерами ОДНОГО твору (тривалості збігаються до
шостого знака) — тобто реально на 4 ноги є 2 різні композиції, не 3. Треба новий трек.

Handover: вихідний трек падає в 0 за `fadeOutMs` (3600), кімната порожніє довше за свій
хвіст (`gapMs` 1500 — позитивне число, не негативне), і лише тоді входить наступний
(`fadeInMs` 3000). Негативний `gapMs` раніше змушував їх грати РАЗОМ — і оскільки t2/t3
ідентичні, це читалось як один трек, що фазується сам із собою.

## Старт вимкненим, аж до жесту

`startMuted: true` у конфізі. Трек фізично крутиться (`ctx.state === 'running'`) з моменту,
коли його файл прийшов у першій хвилі завантаження — але без mute це виглядало б як «звук
сам увімкнувся», тому елемент грає в тиші, і кнопка лише знімає mute.

**Знайдений і виправлений баг:** кнопка звуку показувала «звук» / `aria-pressed="true"` ще
ДО кліку — бо текст керувався фактом «відтворення почалось» (`true`, бо `muted`-елемент
завжди програється), а не фактом «чутно». Тепер напис і атрибут відображають реальний
`muted`-стан, а не факт запуску.
