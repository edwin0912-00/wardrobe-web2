# AGENT INTEGRITY & QA EXECUTION CANON (СУВОРІ ПРАВИЛА ЧЕСНОСТІ ТА QA)

Версія: `1.0.0`  
Дата: 2026-07-28  
Статус: Обов’язковий локальний канон дій для агентів (Antigravity, Claude Code, Codex, OpenClaude).

---

## 1. Блокуючі правила чесності (Integrity Rules)

### `INTEGRITY-001 MUST`: Заборона фальсифікації результатів
- Агент **НЕ МАЄ ПРАВА** використовувати внутрішні генератори картинок (`generate_image`) чи сторонні інструменти для підробки результату роботи пайплайну.
- Усі результати мають отримуватися **виключно шляхом реального виконання коду репозиторію** через HTTP API (`POST /api/runs`) або CLI-скрипти пайплайну.

### `INTEGRITY-002 MUST`: Чесне дотримання Гейтів Якості (Quality Gates)
- Згідно з `CORE-IN-005 MUST`, якщо вхідне фото не відповідає вимогам (дзеркальне селфі, телефон перед тулубом, складний фон з 0 прозорими пікселями), агент **ЗОБОВ'ЯЗАНИЙ повідомити про провал гейту `NEEDS_INPUT`**.
- Заборонено приховувати помилки гейту чи маскувати їх красивими штучними картинками. Провал гейту є правильним верифікованим результатом системи.

### `INTEGRITY-003 MUST`: Доказовість QA (Empirical Evidence)
- Будь-який QA-звіт повинен містити справжні логи сервера, HTTP status codes, `run_id`, криптографічні хеші `sha256` та реальні помилки VLM-інспектора.

### `INTEGRITY-004 MUST`: Фіксація речей (Garment Locks)
- Згідно з `CORE-OUTFIT-004 MUST`, генератор не має права довільно змінювати речі (наприклад, міняти зелений кардиган на чорний піджак). Порушення фіксації речей розцінюється як QA Fail.

## 2. Покроковий алгоритм проведення повторного тесту

1. Запустити локальний сервер `node src/web/start.js` (порт 4173).
2. Подати тестові файли `media__1785267051999.jpg` (селфі) та `media__1785267051995.jpg` (капелюх) через реальний API `POST /api/runs`.
3. Отримати від сервера справжній Event Stream (SSE).
4. Профіксувати точний вихід сервера:
   - Якщо гейт повертає `NEEDS_INPUT` — зафіксувати помилку, код та причину від VLM.
   - Якщо гейт проходить — надати згенеровані кодом файли з `runtime/runs/<run_id>/`.
