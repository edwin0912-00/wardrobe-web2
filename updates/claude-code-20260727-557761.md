## 3. Magnific as an app provider — how it can actually be done

Magnific publishes a REST API: `POST https://api.magnific.com/v1/ai/mystic`,
auth header `x-magnific-api-key`, async task pattern returning `task_id` with
`CREATED / IN_PROGRESS / COMPLETED / FAILED` and a `generated` URL list. That
shape matches the existing provider contract used by
`src/providers/openrouter-imagegen-provider.js`, so a
`magnific-imagegen-provider.js` is a small, testable addition rather than a new
architecture.

What blocks it: an API key. It is a credential and must be issued by the
operator from the Magnific account and stored the way the host already stores
`openrouter-api-key`, never in Git.
