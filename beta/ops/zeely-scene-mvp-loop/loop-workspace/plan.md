# Scene MVP plan

1. Validate the strict scene catalog and exact prompt inventory.
2. Generate ten standard 4:5 fashion mood cards and four Edwin direction cards.
3. Normalize final assets to production preview WebP and create SHA-256 manifest entries.
4. Build standard and editorial contact sheets.
5. Run deterministic file, ratio, diversity, manifest and privacy checks.
6. Run independent visual review and structured judge gate.
7. Revise only cards with named blocking issues, then repeat checks.
8. Stop only when all fourteen finals pass or a hard guard fires.
